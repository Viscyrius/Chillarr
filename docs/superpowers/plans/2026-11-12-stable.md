# Chillarr 0.20.0 "Stable" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the recurring bugs at their root (dub audio, hide, stray chapters, activity, phone deletes, constant redraws), add range Download/Delete, a new style and a Custom shade, then ship 0.20.0.

**Architecture:** Each fix replaces a rule that judged the wrong thing (a release name instead of its languages, a copy's max instead of its sequence, Jellyfin's clock instead of Chillarr's, a style rule instead of the server) with one that judges the real thing, plus a unit test using the real data that broke it.

**Tech Stack:** Tauri 2, Rust (src-tauri/src), vanilla JS ES modules (src/js), Jellyfin 12.1, Sonarr/Radarr v3 API, Suwayomi GraphQL.

**Spec:** the user's message of 2026-11-12 + issues Viscyrius/Chillarr #77 #78 #80 #81 #82, and the four diagnoses summarised under each task.

## Global Constraints

- Work on branch `stable` in `Github\Chillarr-wt-stable` (based on `search-fixes`, release 0.19.2).
- Copy: no em dashes, short plain words, no jargon.
- Every slider or colour picker applies while dragging (one push per frame, last value always lands), saves on release.
- Claude writes `CHANGELOG.md` for Chillarr.
- New code ships optimized: no full redraw where a patch will do, no polling of a hidden page.
- Verify: `cd src-tauri && cargo test --lib` and `cargo check`; JS by `node --check` on changed files plus a WebKit/Edge run where noted.

## Review Focus

### Task 1: Dub grab rules judge the language, not the word "dual"

Diagnosis: `HAS_DUB` (pick.rs:281) rewards any "Dual Audio/Multi/Dub", so `[DUAL JAP PT-BR]` and `Dual Audio Dublado` scored as dubs. `DUB_WORDS` (pick.rs:223) has no `pt-br|ptbr|dublado`. The live "extra dub" pattern holds backspace bytes (`\x08`) and `ensure_format` throws the update result away (pick.rs:344), so it rejects nothing.

**Files:** Modify `src-tauri/src/pick.rs` (DUB_WORDS, HAS_DUB, has_dub_pattern, ensure_format); tests in its `mod tests`.

- [ ] Write failing tests with the real names, matched through `fancy_regex`:
  - `pt_br_dual_is_a_foreign_dub`: `[Anitsu] Mushoku Tensei - 13 [DUAL JAP PT-BR] [SUB PT-BR ENG]` matches the extra-dub pattern and does NOT match has-dub for `eng`.
  - `dublado_is_a_foreign_dub`: `The Walking Dead S06E16 1080p Dual Audio Dublado` same.
  - `plain_dual_audio_is_neutral`: `[SubsPlease] Breeze - 03 (1080p) Dual Audio` does not match has-dub(eng) and not extra-dub.
  - `named_english_dual_is_preferred`: `[Judas] Show - 03 [Dual-Audio] [ENG]` and `Show S01 English Dub 1080p` match has-dub(eng).
  - `original_only_still_downloads`: `audio_scores("dub").1 == 0` (dub-only never forced, original-only never rejected).
  - `stored_pattern_has_no_control_chars`: `same_specs` returns false when the stored value contains any char `< ' '`.
- [ ] Run `cargo test --lib pick::` : FAIL.
- [ ] Implement: DUB_WORDS adds `dublado|ptbr|pt-br|pt|vostfr`-free safe tags (`dublado|pt-?br`). Has-dub for `eng` = `(?i)((dual|multi)[ ._-]?audio|dual).*(?<![a-z0-9])(eng|english)(?![a-z0-9])|(?<![a-z0-9])eng(lish)?[ ._-]?dub(bed)?(?![a-z0-9])`, but a name that also matches a foreign dub word never counts. `ensure_format`: log the update error; on error delete and recreate the format and re-score profiles; `same_specs` treats control chars as different.
- [ ] Run tests: PASS. Run Fix once against live Sonarr/Radarr, then `GET /api/v3/customformat` shows no `\b` bytes.
- [ ] Commit `Dub: a release must name English to count as a dub; Brazilian dubs are refused; a broken rule is rebuilt`.

- [ ] Rust test `jellyfin_audio_pref_follows_dub`: `audio_lang_pref("dub","eng") == Some("eng")`, `audio_lang_pref("sub", _) == Some("jpn")`-free: sub returns `None` (original).
- [ ] Implement: saving `audio_pref` (and on start) writes each profile's Jellyfin `Configuration.AudioLanguagePreference` + `PlayDefaultAudioTrack=false` for dub; carry only overrides when the user picked the track by hand (`carried.manual === true`); `preferredAudio` also matches `title`/`displayTitle` `/\benglish\b/i`; no English in dub mode shows a toast "This copy has no English voices".

### Task 3: A chapter number must fit its copy's own run

Diagnosis: everything trusts `max(number)` (suwayomi.rs:632, read.rs:262, read.rs:1193). Swordborne MangaK = 1..120 weekly + `276` dated 2026-01-13 (17 pages, another manga); Murim Manhwatop = 1..147 + 559, 560 (9 pages, all same date). `known_upto`/`told` are saved at 276/560, so real 121+ never auto-download. 560's pages are AVIF; `read_core::dims` has no AVIF branch (stretched pages).

**Files:** Modify `src-tauri/src/read_core.rs` (new pure fn), `src-tauri/src/read.rs` (merge_copies, follow, load migration), `src-tauri/src/suwayomi.rs:632`, `src-tauri/src/keepup.rs:167`.

**Interfaces:** Produces `pub fn trusted(own: &[(f64, Option<i64>)], others: &[f64]) -> Vec<bool>` (per chapter: keep?) and `pub fn trusted_top(...) -> Option<f64>` in read_core.

- [ ] Failing tests in read_core: `swordborne_276_dropped` (MangaK 1..=120 weekly dates + 276 old date, other copy tops 116: top 120), `murim_559_560_dropped` (1..=147 + 559, 560, same dates, no others: top 147), `backed_tail_is_kept` (1..=6, 1193..=1198 with another copy at 1198: all kept), `extras_kept` (10.5 style kept), `holes_filled_ok` (1..50 minus 20..25 kept), `avif_dims` (dims of a 32-byte AVIF ispe box header).
- [ ] Rule: walk sorted numbers; the run ends before the first gap > `max(10, 0.25 * run_end)`; later numbers kept only if another copy's own run reaches them; drop a number whose real upload date is older than the median of the run's last 5 dates (skip when all dates equal).
- [ ] Apply in `merge_copies`, `one_source.latest`, `tell_behind`; on load, lower `known_upto`/`told` above the trusted top to the trusted top.
- [ ] Tests pass; check Swordborne and Murim in the app show 120/147 and 121+ queue.
- [ ] Commit.

**Interfaces:** `hidden::keys_for(app, uid) -> HashSet<String>` (always the full list); `hidden::unlock(app, device, pw)`; `hidden_reset(profile)` owner-only Tauri command; `hidden_items` (only when unlocked on this device).
